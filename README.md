## Overview

This portfolio is a fully responsive single-page website designed to present experience, projects, skills, resume access, and contact details in a clean, modern layout. It includes a polished mobile navigation menu, smooth section jumping, animated reveal effects, and interactive project cards.

## Key Features

- Responsive header with a hamburger menu for mobile devices.
- Smooth navigation between Home, About, Skills, Projects, Experience, Resume, and Contact sections.
- Theme switcher with saved preference using `localStorage`.
- Animated hero content with typewriter role text.
- Interactive project filters and polished card transitions.
- Additional projects section with hover-based motion.
- Client-side contact form validation.
- Accessibility-friendly semantic structure and keyboard focus states.
